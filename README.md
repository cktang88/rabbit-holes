# Rabbit Holes

29 browser experiments in the spirit of [neal.fun](https://neal.fun), each built to hold you for an afternoon rather than five minutes, and each set in its own world: a Cold War code office, a 1680 chart table, a harpsichord workshop, a lamplit petri dish.

Every experiment is a single static page with no build step, no backend and no accounts. Progress saves to `localStorage`, so you can close the tab and come back. They work on phones, including touch gestures.

**Play:** https://cktang88.github.io/rabbit-holes/

The landing page groups everything by tag. Subjects: Physics, Maths, Simulation, Language & codes, Art & craft, Biology, Logic & computing, Emergence, Earth & water, Space, Light & sound, Money & trade, Real history. Vibes: Wait, what?, Pretty to watch, Build a machine, Detective work, Strategy, Chill sandbox, Quick hits, Brain-burners.

## How it was made

Ideas came from random walks through Wikipedia and from random items in museum collections, arXiv, the Internet Archive and patents, so they wouldn't cluster around the obvious. See [IDEAS.md](IDEAS.md), [IDEAS-2.md](IDEAS-2.md), [IDEAS-3.md](IDEAS-3.md) and [IDEAS-4.md](IDEAS-4.md). Each idea was checked for prior art, built, and then put through five passes:

- **Bugs and edge cases:** logic tests for every game.
- **Art direction** ([ART-DIRECTION.md](ART-DIRECTION.md)): every game has its own typefaces, materials and in-world controls, with no shared dashboard look.
- **Fresh-eyes review:** critics who didn't build a game scored whether it makes sense and whether it has depth ([REVIEW.md](REVIEW.md)). Anything shallow or confusing was then redesigned.
- **Difficulty rule:** every game has scripted naive players (random, greedy, idle) and a test that they fail the late levels while a competent strategy wins.
- **Phones:** layout checks in portrait and landscape, plus touch-gesture tests.
